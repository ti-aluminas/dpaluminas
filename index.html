ALUMINAS Sistema de Admissão
Fluxo de admissão · RH → DP → Segurança do Trabalho

Onde você trabalha na admissão?

Escolha seu setor para preencher, enviar ou revisar os dados dos funcionários. Cada perfil só acessa o que é permitido para sua etapa.

Etapa 1

RH

Cadastra os dados pessoais do candidato assim que ele chega e envia para o DP dar sequência.

→
Etapa 2 e 4

DP

Vê tudo: dados pessoais, contratuais, bancários e da segurança do trabalho. Envia para o técnico e finaliza a admissão.

→
Etapa 3

Técnico de Segurança

Vê apenas dados básicos e cargo/empresa. Preenche exame e ASO, depois devolve para o DP.

→

Acesso ao sistema

Faça login com o e-mail e senha cadastrados pelo DP para ver os dados do seu setor. Nenhum dado é exibido antes do login.
